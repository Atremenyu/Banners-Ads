# ⚡ DesignKit Studio — Suite de Herramientas Creativas & Marketing

¡Optimiza banners, analiza textos para SEO, genera URLs UTM, extrae paletas de color, calcula relaciones de aspecto, crea códigos QR y diseña gradientes CSS en segundos de forma 100% local y privada!

**DesignKit Studio** es una suite de herramientas web profesionales creada para diseñadores, creadores de contenido, redactores y digital marketers.

---

## 🛠️ Herramientas Incluidas en la Suite

### 1. 🖼️ Optimizador y Recortador de Banners (`/`)
* **Formatos Estándar (Google AdSense e IAB)**: Presets como Robapáginas Medio (300x250), Megabanner (728x90), Rascacielos Ancho (160x600) y dimensiones custom.
* **Recorte Interactivo**: Reencuadre y ajuste visual en tiempo real.
* **Compresión WebP, JPEG, PNG**: Control de calidad (0-100%) y comparador de peso final.
* **Descarga Masiva en ZIP**: Exportación empaquetada o individual.

### 2. ✍️ TextLab & SEO Assistant (`/texto`)
* **Transformación de Caso**: MAYÚSCULAS, minúsculas, Title Case, Sentence case, camelCase, kebab-case, snake_case.
* **Limpieza de Texto**: Eliminación de acentos, espacios dobles, saltos de línea, etiquetas HTML y emojis.
* **Métricas en Tiempo Real**: Caracteres, palabras, oraciones, párrafos y tiempo de lectura.
* **Límites SEO & Social**: Google Meta Title (60), Meta Description (160), X/Twitter (280), Instagram (2,200) y LinkedIn (3,000).

### 3. 🚀 UTMCraft — Creador de Enlaces de Marketing (`/utm-builder`)
* **Parámetros UTM**: `utm_source`, `utm_medium`, `utm_campaign`, `utm_term` y `utm_content`.
* **Presets de Canal**: Google Ads, Facebook Ads, Instagram Bio, Email Newsletter, LinkedIn y TikTok Ads.
* **Historial de Sesión**: Registro temporal de URLs generadas.

### 4. 🎨 ColorStudio & Accesibilidad WCAG (`/color-studio`)
* **Extractor de Paletas**: Sube imágenes para extraer los 6 colores dominantes (HEX, RGB, HSL).
* **Comprobador de Contraste WCAG 2.1**: Relación de contraste exacta y validación AA / AAA para texto normal, grande e interfaces.
* **Exportación de Paletas**: Genera variables CSS `:root`.

### 5. 📐 RatioCalculator & Dimensiones (`/aspect-ratio`)
* **Calculadora de Aspect Ratio**: Recalcula dimensiones en píxeles (16:9, 4:5, 1:1, 9:16, 4:3, 21:9).
* **Cheatsheet Integrado**: Dimensiones para Instagram, YouTube, TikTok y Google Ads.

### 6. 📱 QRStudio — Generador de Códigos QR (`/qr-studio`)
* **Múltiples Formatos**: Genera QR para URLs web, texto libre, chats de WhatsApp directos y conexión Wi-Fi sin clave.
* **Personalización**: Ajuste de colores de módulos y fondo, tamaño en px y nivel de corrección de errores (L, M, Q, H).
* **Exportación**: Descarga en PNG de alta resolución o SVG vectorial.

### 7. 🌈 GradientStudio — Gradientes CSS & Fondos HD (`/gradient-studio`)
* **Tipos de Gradiente**: Lineal, Radial y Cónico con control de ángulo.
* **Paradas de Color Múltiples**: Añade y ajusta posiciones y tonos con slider interactivo.
* **Presets Destacados**: Cyberpunk Neon, Sunset Glow, Emerald Mint, Royal Violet, etc.
* **Exportación**: Copia código CSS, clases Tailwind CSS o descarga imagen HD (1920x1080).

---

## 🔒 Privacidad 100% Local
* Todo el procesamiento ocurre en el navegador del cliente. Tus imágenes, textos y enlaces nunca se envían a ningún servidor externo.

---

## 💻 Desarrollo Local

```bash
# 1. Instalar dependencias
npm install

# 2. Iniciar servidor de desarrollo
npm run dev

# 3. Compilar para producción (SSG)
npm run build
```
